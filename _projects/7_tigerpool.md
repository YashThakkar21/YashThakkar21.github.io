**React · Flask · PostgreSQL · Google Maps API** — 2025 · [Code]({{ page.github }})

Getting from Princeton to an airport is a solved problem only if you know someone leaving at the same time. TigerPool is a full-stack ridesharing platform that matches students on overlapping routes and departure windows, built around the trips students actually take — breaks, airport runs, and trips into the city.

- **React frontend** with search and matching over active trips.
- **Flask + PostgreSQL backend** handling trip lifecycle, matching, and rider coordination.
- **Google Maps API integration** for real-time route optimization and ETA prediction.

The project facilitated 50+ student carpools.

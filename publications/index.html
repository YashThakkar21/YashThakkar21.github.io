2026

  1. RL
    Multi-Agent Reinforcement Learning for Imperfect-Information Games
    Yash Thakkar
    May 2026
    Abstract PDF Code

    Judgment is a trick-taking card game in which players must bid the exact number of tricks they will win before play begins, under partial observability of all other hands. We train agents with a multi-agent self-play loop using PPO with action masking over the legal move set and belief-state features derived from bidding behavior and observed play. The resulting agents surpass experienced human players and develop emergent bidding strategies, including deliberately conservative bids that constrain opponents’ targets, learned directly from raw game states without hand-engineered heuristics.

  2. LLM
    A Smarter Search for Tree of Thoughts
    Yash Thakkar
    May 2026
    Abstract PDF Code

    Tree of Thoughts (ToT) explores a tree of intermediate reasoning steps but searches it with uninformed BFS or DFS. We replace this with two informed search strategies: A* using a lazily evaluated LLM-scored heuristic, which avoids scoring every frontier node given the cost of each model call, and Monte Carlo Tree Search with UCT exploration using the LLM as a leaf value estimator. Benchmarking against BFS/DFS baselines on Game of 24 and crossword tasks, we find that gains from search are bounded by evaluator calibration: MCTS outperforms BFS only when state evaluations are reliable, and poorly calibrated evaluators cause informed search to amplify rather than correct their errors.

  3. Robotics
    A Low-Cost Open-Source Platform for Autonomous Drone Payload Delivery
    Yash Thakkar
    May 2026
    Abstract PDF Code

    Commercial drone delivery hardware is expensive and closed. I present an open-source autonomous payload-drop system built from commodity components: an Arduino control board, an ultrasonic rangefinder for above-ground-level release triggering, and 3D-printed release mechanisms with a published CAD parts library. Across seven design revisions driven by failure analysis of servo torque, rotor-downwash sensor noise, and mechanical binding, the final design achieves 84% bench and 80% in-flight release reliability, with the remaining gap attributable to vibration-induced sensor noise absent under static testing.

  1. LLM
    Semantic Reasoning Evaluation in Large Language Models
    Yash Thakkar
    Dec 2025
    Abstract PDF Code

    When a code model correctly describes a function named binary_search, it is unclear whether it traced the program’s logic or read its identifier. I construct synthetic datasets that hold program semantics fixed while varying surface form, and evaluate Qwen2.5-Coder-32B under identifier-obfuscation and injected-error ablations using an LLM-as-a-judge protocol for free-form output. The model preserves intent under obfuscation, indicating its understanding is not purely lexical, but fails at multi-step error localization: accuracy degrades sharply as the number of reasoning steps between an injected fault and its observable effect grows.

  2. CV
    Benchmarking Classical and Foundation-Model Pipelines for Pedestrian Detection
    Yash Thakkar, and S. Bhatia
    Dec 2025
    Abstract PDF Code

    Pedestrian detection methods spanning four decades are rarely compared under identical conditions. We benchmark HOG, CNN, ViT, and SAM2 pipelines on the PnPLO pedestrian dataset with fixed data, splits, and evaluation protocol. Foundation-model pipelines lead on detection quality, particularly for occluded and small-scale pedestrians where hand-engineered gradient features degrade, but incur inference costs orders of magnitude higher, which is the binding constraint for the embedded real-time settings where pedestrian detection is deployed. HOG remains competitive on clean, unoccluded instances at a fraction of the compute.
